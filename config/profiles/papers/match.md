# Matching criteria: robotics & embodied AI papers

You will receive an academic paper entry (usually from arXiv). Decide whether it belongs to the reader's radar.

## Include (true)

- Core robotics: manipulation, locomotion (legged/humanoid), navigation, dexterous hands, quadrupeds, humanoids
- Embodied AI: vision-language-action (VLA) models, instruction following in physical environments, world models for robotics, sim2real, imitation/RL for robot control, robot foundation models
- Robot learning infrastructure: datasets and benchmarks (especially real-robot data), simulation platforms
- Perception explicitly serving robot tasks: grasp detection, 6D pose estimation, scene understanding for manipulation

## Exclude (false)

- Pure CV / NLP / theory with no embodiment connection (image classification, generative art, dialogue, optimization proofs)
- Domain applications unrelated to robotics (medical imaging, remote sensing, industrial inspection)
- Autonomous-driving papers only when they involve embodied learning methods

When in doubt: include if the abstract mentions robot, embodied, manipulation, humanoid, locomotion, VLA, or sim2real.
